Update the existing Stonegate Intelligence Group application so that the Client Portal, Clients, Cases, and Billable Hours system are properly connected.

Do not create a separate application. Inspect the existing code and database first and integrate these changes into the current architecture.

1. CONNECT CLIENTS TO BILLABLE HOURS

Each client in the existing Client Portal must have a unique Client ID.

Each client should be able to have one or more Cases / Engagements.

The relationship should be:

Client
→ Cases / Engagements
→ Time Entries
→ Invoices

Every billable time entry must be associated with:

* Client ID
* Case / Engagement ID
* User / Investigator ID

Do not associate clients to time entries using only the client’s name. Use database IDs/foreign keys so records remain accurate if a client’s name changes.

Enforce all client filtering and access control on the backend.

Do NOT rely solely on frontend filtering.

Every database query for client billing/time entries must verify the user’s authorization to access that client.

A user must never be able to access another client’s billing information simply by changing a URL parameter or Client ID.

Use the existing authentication and authorization system.
